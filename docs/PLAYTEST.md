# Плейтест «Ветров»: что проверить в Studio

35–45 минут. Порядок: запуск → полёт → доставка → гонка → телефон → вдвоём → магазин → отладка.
Всё, что на заглушке движка проверить нельзя (физика корзины с сиденьем, сетевой владелец, камера, свет, облака, вид шара), — здесь.

## 0. Запуск (3 мин)
```powershell
git pull
rokit install
rojo build -o game.rbxl
```
Открой `game.rbxl`, **View → Output**, **Play** (F5).
- [ ] Персонаж появляется **сидя в корзине шара** на поле гавани (большой остров в центре) через 1–2 с.
- [ ] В Output нет красных строк. Есть `[World] seed N built in … s`.
- [ ] Через ~5 с: `[SELFTEST] RESULT 8/8 passed`. Ожидаемые WARN: `products configured` (ID = 0) и `player data saves` (если не включён доступ к API).
- [ ] Главная строка самотеста: `PASS players fly: balloon, seat, lift constraint (1/1 seated with a Lift)`. Если FAIL — см. `LOCAL_SESSION.md`, «Типичные проблемы».

## 1. Полёт — главный риск «ватного» управления (8 мин)
| Что | Проверь |
|---|---|
| Взлёт | Держи **W** (или Пробел): пламя горелки и звук **сразу**, шар идёт вверх без раскачки. Отпусти — шар **останавливается** на высоте (не продолжает ползти). |
| Спуск | Держи **S**: шар идёт вниз. Над полем — садится и стоит. |
| Слои | Поднимись: вокруг летят **цветные ленты ветра**; ленты твоего слоя ярче. Смена цвета лент = новый слой, короткий звук. |
| **Поворот** | Стоя в одном слое, нажми W до следующего: **ленты на углах корзины разворачиваются сразу**, шар поворачивает за ~1–1,5 с. Это главное ощущение игры. **Кажется ли управление «ватным»?** Если да — запиши, что именно: медленно поднимается / медленно поворачивает / не понятно, где граница слоя. |
| Лестница ветров | Справа (левее кнопок) — строки слоёв, стрелка = куда несёт на этой высоте. Поверни камеру (правая кнопка мыши) — **стрелки поворачиваются вместе с камерой**. Маркер ◀ ползёт по высоте вместе с шаром, твой слой обведён. |
| Цель на лестнице | Слои, которые дуют к цели (заказ или чекпоинт), подсвечены **✓** (зелёный) или **·** (жёлтый). Стрелка цели — в заголовке лестницы. **Понятно ли без объяснений, что надо подняться к «✓»?** |
| Потолок | Держи W долго: на высоте ~256 шар упирается, тост «воздух слишком редкий». |
| Камера | Видно весь шар, камера не проваливается в оболочку, не дёргается. |

## 2. Доставка (7 мин)
| Что | Проверь |
|---|---|
| Заказ | Слева снизу «Посылка → крыша на острове · N м», стрелка к цели. Над крышей-целью **золотой столб** и кольцо на крыше. |
| Метка падения | Под шаром на воде/земле — белый круг ✕ и точки траектории: посылка падает не вертикально, её сносит ветрами слоёв. Поменяй высоту — **метка смещается**. |
| Сброс | Подведи метку на крышу (она станет зелёной) — посылка **сама** падает с красным парашютом, тост «Посылка сброшена!», потом «Доставлено! +N», новый заказ. |
| Быстро | DBG → «→ above the order»: тебя ставит так, что посылка сразу падает на крышу. |
| Другой заказ | Кнопка меняет крышу; повторно — только через 8 с. |

## 3. Гонка (10 мин)
DBG → **Race now** (или дождись таймера «Гонка через …» сверху).
| Момент | Проверь |
|---|---|
| Старт | Тебя переносит на поле гавани, рядом 5 ИИ-шаров с подписью «· AI». Крупно 3-2-1, шар **не двигается** во время отсчёта, затем «ВПЕРЁД!». |
| Чекпоинт | Следующий — яркий столб с номером и цветными стрелками ветра на высоте каждого слоя; остальные — блёклые. Сверху «→ Чекпоинт 1/4 · N м ⏱». **Помогают ли стрелки на столбе выбрать слой?** |
| ИИ | Шары ИИ летают плавно, меняют высоту (пламя!), расходятся по разным слоям. Не дёргаются. |
| Места | Таблица мест справа сверху (на телефоне — слева). |
| Море | DBG → «Splash (sea)»: «Шар намок!», через ~3 с ты над последним пройденным чекпоинтом. |
| Финиш | DBG → «→ finish» или долети: тост «Финиш! N-е место», через 45 с после первого финиша — окно итогов (место, время, монеты, список). В leaderstats — Coins и Wins. |
| После | Заказ доставки появляется снова через несколько секунд. «Не участвую» на баннере — следующая гонка без тебя. |

## 4. Телефон (5 мин)
**Test → Device** (эмулятор) → маленький телефон (iPhone SE) горизонтально, затем планшет.
- [ ] Стика и кнопки прыжка нет. Две большие кнопки **▲ ВЫШЕ / ▼ НИЖЕ** справа снизу, их легко держать большим пальцем; одновременное нажатие = держать высоту.
- [ ] Лестница ветров не перекрывает кнопки, стрелки и ✓ различимы.
- [ ] Баннер сверху, монеты слева, таблица мест в гонке (слева под монетами) — ничего не налезает.
- [ ] Магазин и итоги целиком на экране, листаются пальцем.
- [ ] Камера крутится пальцем.

## 5. Вдвоём (5 мин)
**Test → Clients and Servers**, 2 игрока → **Start**.
- [ ] Шар другого игрока двигается плавно; его пламя загорается, когда он жмёт ВЫШЕ; его ленты развеваются.
- [ ] Шары проходят друг сквозь друга (не толкаются).
- [ ] Гонка: оба на старте, в таблице оба и ИИ (ИИ добавляется до 6 шаров).
- [ ] Косметика, купленная одним, видна второму (цвет шара, след).

## 6. Магазин (5 мин)
- [ ] DBG → «+1000 coins», купи «Небесный» шар — оболочка перекрашивается сразу. След «Розовый» — новый след.
- [ ] **Сундук:** у каждого предмета процент, сверху 60 / 28 / 10 / 2. «Открыть» → окно с выпавшим предметом; дубликат пишет «+N монет».
- [ ] **Пропуска:** VIP → звезда над шаром, доступны золотые шар/ленты/след. «Грузовая корзина» → сразу два заказа. «R$ 49» у редкого предмета → «Studio: покупка эмулирована».
- [ ] Легендарный «Радуга» переливается.

## 7. Отладка (2 мин)
- [ ] DBG: Race now / Stop race / → next checkpoint / → finish / Splash / → above the order / New winds / → ceiling / → harbor / +1000 coins / Reset profile / Self-test / RU-EN.
- [ ] «New winds» — ленты и лестница перекрашиваются/поворачиваются, мачта в гавани обновилась.
- [ ] FPS (**View → Stats** или Ctrl+Shift+F5) в гонке с 6 шарами.

## Как прислать обратную связь
```
SELFTEST: (строки с FAIL/WARN)
Красные строки из Output: (если есть)
Отклик: взлёт сразу да/нет; поворот при смене слоя: быстро / норм / «вата»; что именно мешает:
Слои видны (ленты, лестница, стрелки на столбах): да / нет; что непонятно:
Доставка: попасть на крышу легко / норм / тяжело; метка понятна: да / нет
Гонка: время __; место __; ИИ: слишком сильные / норм / слабые; ИИ двигаются плавно: да / нет
Телефон (эмулятор): кнопки __, лестница __, наложения __
Камера: ок / проваливается / дёргается
Что непонятно новичку:
Что сломано:
```
