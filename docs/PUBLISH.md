# Публикация и монетизация «Ветров»

Общий путь «код → Studio → публикация → открыть для всех» тот же, что в `roblox/docs/PUBLISH.md` (аккаунт старше 2 дней, проверка возраста, анкета Maturity & Compliance, Manage Audience). Здесь — только то, что отличается: товары, ID, настройки места.

> Меню Creator Hub и Studio часто переименовывают. Если пункт называется иначе, ищи по смыслу; официальные страницы: [Passes](https://create.roblox.com/docs/production/monetization/game-passes), [Developer products](https://create.roblox.com/docs/production/monetization/developer-products), [PolicyService](https://create.roblox.com/docs/reference/engine/classes/PolicyService).

## 1. Первая публикация (приватно)
1. `rojo build -o game.rbxl`, открой в Studio.
2. **File → Publish to Roblox** → новая игра. Название и описание — ниже.
3. Creator Hub → игра → **Places** → стартовое место → **Server size: 12** (гонка до 12 шаров).
4. В Studio: **Game Settings → Security → Enable Studio Access to API Services** — иначе в Studio профиль не сохраняется (самотест покажет WARN `player data saves`).
5. **Game Settings → Avatar**: оставь R15. Анимации по умолчанию (персонаж сидит в корзине).

С этого момента работай с облачным местом: Creator Hub → **Edit in Studio** → `rojo serve` → **Connect**.

## 2. Товары: создать и вписать ID
Creator Hub → игра → **Monetization**.

### Геймпассы (Passes → Create a Pass)
| Ключ в `Config.Passes` | Название | Цена (рекоменд.) | Иконка |
|---|---|---|---|
| `DoubleCoins` | ×2 Coins / ×2 Монеты | 149 R$ | золотая монета «×2» на фоне шара |
| `Cargo` | Cargo basket / Грузовая корзина | 99 R$ | корзина шара с двумя посылками |
| `Vip` | VIP | 249 R$ | золотой шар со звездой |

После создания: вкладка **Sales** → **Item for Sale** → цена → Save. ID — в адресе страницы пасса или в меню «…» → **Copy Asset ID**.

### Developer Products (Developer Products → Create)
| Ключ в `Config.Products` | Название | Цена (рекоменд.) |
|---|---|---|
| `Coins500` | 500 coins | 25 R$ |
| `Coins3000` | 3000 coins | 99 R$ |
| `Chest` | Wind Chest / Сундук ветров | 35 R$ |
| `DirectRare` | Rare item / Редкий предмет | 49 R$ |
| `DirectEpic` | Epic item / Эпический предмет | 99 R$ |
| `DirectLegendary` | Legendary item / Легендарный предмет | 199 R$ |

### Вписать ID
`src/shared/Config.luau`:
```lua
Config.Passes = {
	DoubleCoins = { id = 123456789, robux = 149 },
	...
}
Config.Products = {
	Coins500 = { id = 987654321, robux = 25, coins = 500 },
	...
}
```
`robux` — запасная цена для интерфейса: игра сама запрашивает настоящую цену у Roblox (`GetProductInfo`), так что менять цену можно только в Creator Hub.

**Пока ID = 0:** в Studio покупка эмулируется (тост «Studio: покупка эмулирована»), в живой игре кнопка показывает «скоро». Самотест выводит WARN со списком товаров без ID.

**Почему нет товаров «быстрее»:** скорость шара не продаётся (в магазине так и написано) — гонка честная, иначе новички уходят. Платное — внешний вид (видят все), удобство (вторая посылка) и монеты.

## 3. Сундук и правила Roblox о случайных наградах
Уже сделано в коде:
- шанс **каждого** предмета показан до покупки (вкладка «Сундук»), сумма ровно 100%: Common 60% · Rare 28% · Epic 10% · Legendary 2%;
- дубликат превращается в монеты, сумма показана заранее;
- сервер спрашивает `PolicyService:GetPolicyInfoForPlayerAsync`; если `ArePaidRandomItemsRestricted` или запрос упал, сундук скрыт и сервер **отказывается** открыть промпт; остаётся прямая покупка любого предмета за монеты и за Robux.

Что сделать тебе:
- в анкете **Maturity & Compliance** честно отметить **платные случайные предметы** (paid random items), если такой вопрос есть; насилия и страшного в игре нет — ожидаемый рейтинг Minimal;
- если меняешь шансы в `Config.Rarity`, запусти `lune run tests/run.luau`: тест не даст сломать сумму 100%.

## 4. Robux и Беларусь
DevEx недоступен, Robux копятся на балансе. Их выгоднее всего тратить на рекламу (Ads Manager → спонсорские показы) в первые недели: без игроков монетизация не работает. Гонки хорошо смотрятся в рекламе: 10-секундный ролик «шары расходятся по разным слоям» объясняет механику без слов. Даже одному игроку есть с кем гоняться — пустые места занимают ИИ-соперники, так что игра не выглядит пустой в первые дни.

## 5. Страница игры
**Название:** `Winds: Balloon Race` (EN), `Ветра: гонка воздушных шаров` (RU — через Creator Hub → Localization).

**Описание (EN):**
> Your balloon has only two buttons: UP and DOWN. You can't steer — but every layer of the sky blows a different way. Watch the colored wind ribbons, climb into the layer that blows where you need to go, and race up to 12 balloons around the islands. Between races, drop parcels onto rooftops — the wind carries them as they fall, so aim with the drop marker. Easy to learn on a phone, hard to master.

**Описание (RU):**
> У твоего шара всего две кнопки: ВЫШЕ и НИЖЕ. Повернуть нельзя — но каждый слой неба дует в свою сторону. Смотри на цветные ленты ветра, поднимайся в слой, который несёт куда надо, и обгоняй до 12 шаров между островами. Между гонками сбрасывай посылки на крыши: ветер сносит их, пока они падают, — целься меткой. Научиться — минута, стать лучшим — сложнее.

**Жанр:** Racing (или Adventure). **Иконка 512×512:** три шара разных цветов на разной высоте, у каждого — своя цветная лента ветра, уходящая в свою сторону; снизу остров. **Скриншоты 1920×1080:** старт 6 шаров на поле гавани; шары на трёх высотах расходятся веером; лестница ветров крупно (интерфейс); столб чекпоинта со стрелками; посылка с парашютом над крышей и метка ✕; магазин с шансами. DBG → «Race now» помогает собрать кадр.

## 6. Перед открытием для всех
- [ ] Все ID вписаны, самотест без FAIL и без WARN о товарах.
- [ ] Покупка каждого товара проверена в живом клиенте (Creator Hub → Play) с тестовым аккаунтом; Robux списываются, товар выдаётся один раз.
- [ ] «Грузовая корзина»: сразу два заказа. VIP: золотой шар доступен, звезда над шаром.
- [ ] Перезаход: монеты, косметика, победы на месте.
- [ ] Server size = 12. Проверено на телефоне (живой клиент, не только эмулятор): кнопки нажимаются большим пальцем, лестница читается.
- [ ] Гонка вдвоём в живом сервере: чужой шар двигается плавно (не дёргается), его пламя видно.
